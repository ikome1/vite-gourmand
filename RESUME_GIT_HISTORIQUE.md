## 🚀 Prochaines Étapes : Fusionner Dev dans Main

Quand vous êtes prêt à fusionner `dev` dans `main`, utilisez ces commandes :

```bash
# 1. Basculer sur la branche main
git checkout main

# 2. Fusionner dev dans main
git merge dev

# 3. Pousser main sur GitHub
git push origin main
```

**OU** via GitHub :
1. Allez sur https://github.com/ikome1/vite-gourmand
2. Créez une Pull Request de `dev` vers `main`
3. Fusionnez la PR
